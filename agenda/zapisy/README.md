# Zápisy a usnesení – SVJ Letohradská 367/5

V této složce se ukládají oficiální zápisy ze shromáždění vlastníků jednotek a hlasování per rollam.

## Struktura souborů zápisů
- `YYYY-MM-DD_shromazdeni.md` – zápis ze zasedání shromáždění.
- `YYYY-MM-DD_per_rollam.md` – zápis a výsledky písemného hlasování mimo zasedání.
